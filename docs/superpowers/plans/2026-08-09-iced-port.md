# datavis → iced UI Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the egui/eframe UI layer of `datavis` with iced 0.14 at full feature parity, reusing the existing data backend untouched.

**Architecture:** One functional iced application (`iced::application::timed(new, update, subscription, view)`). Panels observe data through the existing `ChannelStore` trait. Plot panels own a stateful `iced_plot::PlotWidget` fed by `update_series` on each tick; non-plot panels draw with `iced::widget::Canvas`. The workspace is `pane_grid` (splits only). egui is hard-removed in Task 2.

**Tech Stack:** Rust (edition 2021 crate), iced 0.14 (features `advanced`, `canvas`, `tokio`), iced_plot 0.5, rfd 0.14 (kept), existing crates unchanged.

## Global Constraints

- **iced 0.14** and **iced_plot 0.5** are the only new UI dependencies. Drop `eframe`, `egui`, `egui_plot`, `egui_tiles`, `egui_phosphor` entirely by the end of the plan.
- **iced_plot depends on `iced ^0.14` with feature `advanced` and is `edition = "2024"`** → the build needs Rust **1.85+**. Verify `rustc --version` ≥ 1.85 in Task 1; if lower, STOP and report.
- **`iced_plot::PlotWidget` is stateful** (retains GPU buffers). It lives in panel state and is mutated via `update_series` / `set_*`; never rebuilt inside `view`.
- The functional app API is `iced::application::timed(App::new, App::update, App::subscription, App::view)` where `update(&mut self, Message, Instant)` and `view(&self) -> Element<Message>`. A per-frame tick comes from `iced::window::frames()`; a fixed-rate tick from `iced::time::every(Duration)`.
- **Never** add `Co-Authored-By`, "Generated with Claude", or any AI self-attribution to commits or PRs.
- **Never** stage or commit `config.toml` (local session state) — it must stay an untracked working-tree file.
- Nix: `cache.numtide.com` is forbidden; the flake sets `extra-substituters = []`. Build inside `nix develop` (provides python3 + numba for the `scripting` feature).
- Every task gates on BOTH feature configs, matching current CI: `cargo test --no-default-features` and `cargo test` (default = `scripting`, run inside `nix develop`).
- Panels observe data ONLY through `crate::store::ChannelStore`. Do not add UI knowledge to `ingest/`, `store/`, `record/`, `config/` (except the workspace-layout schema in Task 5), or the `script/` engine.
- The reused `PanelEntry { panel_type: String, config: toml::Table }` contract (in `src/config`) is unchanged. `PanelRegistry` keeps a `panel_type → constructor` map.

## Reference: files reused untouched (do not modify)

`src/ingest/**`, `src/store/**`, `src/record/**` (except reading APIs), `src/config/**` (except `workspace`-layout schema), `src/script/` engine (`mod.rs`, `runner.rs`, `python.rs`, `config.rs` — NOT `panel.rs`), and the data-computation helpers inside the current `viz/*` panels (FFT in `spectrum.rs`, decimation in `decimate.rs`, sample extraction in `common.rs`). - [ ] **Step 3: Write the spike** (`examples/iced_plot_spike.rs`)

```rust
use std::time::Duration;
use iced::time::Instant;
use iced::{Color, Element, Subscription};
use iced_plot::{AxisLink, LineStyle, PlotUiMessage, PlotWidget, PlotWidgetBuilder, Series, ShapeId};

fn main() -> iced::Result {
    iced::application::timed(App::new, App::update, App::subscription, App::view).run()
}

#[derive(Debug, Clone)]
enum Message { Top(PlotUiMessage), Bottom(PlotUiMessage), Tick }

struct App {
    top: PlotWidget, top_id: ShapeId,
    bottom: PlotWidget, bottom_id: ShapeId,
    x: f64, last: std::time::Instant,
}

impl App {
    fn new() -> Self {
        let link = AxisLink::new(); // shared X zoom/pan across both plots
        let n = 100_000usize;
        let s0 = Series::line_only((0..n).map(|i| [i as f64, (i as f64 * 0.001).sin()]).collect(), LineStyle::solid()).with_color(Color::from_rgb(0.2,0.6,1.0)).with_label("a");
        let id0 = s0.id;
        let s1 = Series::line_only((0..n).map(|i| [i as f64, (i as f64 * 0.002).cos()]).collect(), LineStyle::solid()).with_color(Color::from_rgb(1.0,0.4,0.2)).with_label("b");
        let id1 = s1.id;
        let top = PlotWidgetBuilder::new().with_x_axis_link(link.clone()).with_autoscale_on_updates(true).add_series(s0).build().unwrap();
        let bottom = PlotWidgetBuilder::new().with_x_axis_link(link).with_autoscale_on_updates(true).add_series(s1).build().unwrap();
        Self { top, top_id: id0, bottom, bottom_id: id1, x: n as f64, last: std::time::Instant::now() }
    }
    fn update(&mut self, m: Message, now: std::time::Instant) {
        match m {
            Message::Top(p) => self.top.update(p),
            Message::Bottom(p) => self.bottom.update(p),
            Message::Tick => {
                if self.last.elapsed() < Duration::from_millis(16) { return; }
                self.last = now;
                for _ in 0..500 { // push 500 pts/tick to stress the buffer
                    let x = self.x;
                    let _ = self.top.update_series(&self.top_id, |s| { s.positions.push([x, (x*0.001).sin()]); if s.positions.len() > 100_000 { s.positions.remove(0); } });
                    let _ = self.bottom.update_series(&self.bottom_id, |s| { s.positions.push([x, (x*0.002).cos()]); if s.positions.len() > 100_000 { s.positions.remove(0); } });
                    self.x += 1.0;
                }
            }
        }
    }
    fn view(&self) -> Element<'_, Message> {
        iced::widget::column![ self.top.view().map(Message::Top), self.bottom.view().map(Message::Bottom) ].into()
    }
    fn subscription(&self) -> Subscription<Message> { iced::window::frames().map(|_| Message::Tick) }
}
```

pub enum PanelMessage { Plot(iced_plot::PlotUiMessage), Config(ConfigMsg), /* grows per panel */ }

pub trait VizPanel {
    fn title(&self) -> String;
    /// Pull new samples from the store into internal widget state. Called each tick.
    fn sync(&mut self, store: &dyn crate::store::ChannelStore);
    /// Render current state. Pure; no store access (data already synced).
    fn view(&self) -> iced::Element<'_, PanelMessage>;
    /// Handle a panel-local message (pan/zoom/config).
    fn update(&mut self, msg: PanelMessage);
    fn config_view(&self) -> iced::Element<'_, PanelMessage>;
    /// Attempt to bind a dragged channel; return true if accepted.
    fn bind_channel(&mut self, name: &str) -> bool;
    fn serialize(&self) -> toml::Table;
}

pub type PanelCtor = Box<dyn Fn(&toml::Table, &crate::config::ChannelRegistry) -> Box<dyn VizPanel>>;
pub struct PanelRegistry { /* map: String -> (PanelCtor, metadata) */ }
impl PanelRegistry {
    pub fn with_builtins() -> Self;
    pub fn build(&self, entry: &crate::config::PanelEntry, ch: &crate::config::ChannelRegistry) -> Box<dyn VizPanel>;
    pub fn type_names(&self) -> Vec<&str>;
}
